# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities in this repository through GitHub's
[private vulnerability reporting](https://github.com/kennethkau/swift-format/security/advisories/new),
which is enabled for this repository. Do not open public issues for security problems.

For vulnerabilities in upstream swift-format or the Swift toolchain itself, follow the
[Swift security policy](https://www.swift.org/security/).
